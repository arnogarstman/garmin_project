How it works

src/garminreader · transform/
Sources

Pluggable ingest

Each source implements one interface and is registered in sources/__init__.py. Garmin today; TrainMore and Strava slot in without touching it.

Raw

Untouched JSON

API payloads land as-is with load metadata in raw.payloads, only when new or changed, with a run log in raw.loads. A local DuckDB file or MotherDuck.

Transform

dbt on DuckDB

Staging tables keep the newest load per record; marts expose fct_* and rpt_*. No transformation happens in ingest code.

Orchestrate

Dagster

Raw assets partitioned by day, dbt via dagster-dbt, and freshness checks. One run a day keeps it current.

Serve

Streamlit

Reads marts only, through queries.py. Adds an AI coach and training plan against the goal file.
